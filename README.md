# ИМСИТ Payroll Pro (Desktop)

Современное desktop-приложение для расчёта зарплаты с регистрацией пользователей и улучшенным UI.

## Возможности

- Регистрация и вход пользователя (локальная авторизация SQLite, хэширование пароля + salt).
- Современный тёмный интерфейс (ttk + кастомные стили).
- Расчёт payroll: оклад, премия, налог, сверхурочные, фиксированные удержания.
- CRUD сотрудников с хранением в SQLite.
- Unit-тесты для расчётного ядра и авторизации.

## Запуск

```bash
python app.py
```

## Тесты

```bash
python -m unittest discover -s tests -v
```
